Complete reference for all Relay commands. Commands marked with a provider name are only available with that provider.

## Chat

No command needed — just send a message. Supports text, voice notes (requires STT config), photos (vision models), and file attachments.

Input limit: 32,000 characters. Send longer content as a file.

---

## Session Management

### /new [title]

Create a new session. The new session becomes active immediately.

Examples: `/new` or `/new Refactoring auth module`

### /sessions

List all sessions sorted by last modified date.

### /switch \<id\>

Switch to an existing session. Example: `/switch abc123`

### /delete \<id\>

Delete a session. Example: `/delete abc123`

### /current

Show the active session's ID and title.

### /fork [messageId]

Fork the current session. Optionally fork from a specific message. OpenCode and Claude only.

Examples: `/fork` or `/fork msg_abc123`

## Monitor

### /todo

View the AI's task checklist with status icons. OpenCode only.

### /diff

Show a summary of code changes in the current session.

### /diff full

Download the full diff as a text file.

---

## File Operations

### /read \<path\>

Read a file's contents. Files larger than 15KB are sent as attachments.

Example: `/read src/index.ts`

### /find \<query\>

Find files by name pattern. Shows up to 50 matches.

Example: `/find *.json`

### /search \<pattern\>

Search file contents (regex supported). Shows up to 20 matches with file paths and line numbers.

Examples: `/search TODO` or `/search function.*auth`

### /symbols \<query\>

Find code symbols by name. Shows up to 30 matches.

Example: `/symbols authenticate`

### /status

Show git file status.

## History

### /history

View the last 10 messages in the current session.

### /summarize

Generate a session summary. OpenCode only.

### /revert

Undo the last AI change. OpenCode only.

### /unrevert

Redo a reverted change. OpenCode only.

### /abort

Cancel the currently running operation.

### /share

Get a shareable URL for the current session. OpenCode only.

---

## Shell

### /shell \<cmd\>

Run a shell command. On OpenCode, runs natively. On Claude and Codex, the command is sent as a prompt.

Examples: `/shell ls -la` or `/shell npm test`

### /cmd \<command\>

Run an OpenCode-specific command. OpenCode only.

Example: `/cmd compact`

### /commands

List available OpenCode commands. OpenCode only.

---

## Models

### /models

List all available models with capability badges: `[reasoning]`, `[vision]`, `[active]`.

### /model [id]

View or change the current model.

Examples: `/model` to view current, `/model sonnet` to switch by partial match

---

## MCP

MCP servers extend the AI with additional tools. OpenCode and Claude only.

### /mcp

Show MCP server status.

### /mcp add \<name\> local \<cmd\>

Add a local MCP server.

Example: `/mcp add memory local npx -y @modelcontextprotocol/server-memory`

### /mcp add \<name\> remote \<url\>

Add a remote MCP server.

Example: `/mcp add api remote https://mcp.example.com/sse`

### /mcp remove \<name\>

Remove and disconnect a server.
