All commands start with `/` and can be sent in any chat with your bot. Organized by category below.

## Chat

No command needed — just send a message.

**Supported input types:**
- Text messages
- Voice notes (requires STT configuration)
- Photos (sent to vision-capable models)
- File attachments (text files are embedded, binary files referenced)
- **Reply to a message** to include it as context in your prompt
- **Edit a sent message** to re-prompt with the corrected text

Input limit: 32,000 characters. Send longer content as a file.

When the model provides reasoning/thinking, it appears in a collapsible blockquote above the answer.

## Session Management

### /new [title]

Create a new session. The new session becomes active immediately.

Examples: `/new` or `/new Refactoring auth module`

### /sessions

List all sessions sorted by last modified date.

### /switch \<id\>

Switch to an existing session. Example: `/switch abc123`

### /delete \<id\>

Delete a session. Example: `/delete abc123`

### /current

Show the active session's ID and title.

### /rename \<title\>

Rename the current session. Example: `/rename Auth refactor`

### /fork [messageId]

Fork the current session. Optionally fork from a specific message.

Examples: `/fork` or `/fork msg_abc123`

## File Operations

### /ls [path]

List files and directories. Defaults to the project root.

Example: `/ls src/`

### /read \<path\>

Read a file's contents. Files larger than 15KB are sent as attachments.

Example: `/read src/index.ts`

### /find \<query\>

Find files by name pattern. Shows up to 50 matches.

Example: `/find *.json`

### /search \<pattern\>

Search file contents (regex supported). Shows up to 20 matches with file paths and line numbers.

Examples: `/search TODO` or `/search function.*auth`

### /symbols \<query\>

Find code symbols by name. Shows up to 30 matches.

Example: `/symbols authenticate`

### /status

Show git file status.

## History

### /history

View the last 10 messages in the current session.

### /summarize

Generate a session summary.

### /revert

Undo the last AI change.

### /unrevert

Redo a reverted change.

### /abort

Cancel the currently running operation.

### /share

Get a shareable URL for the current session.

### /unshare

Revoke a previously shared session URL.

## Shell

### /shell \<cmd\>

Run a shell command natively on the OpenCode server.

Examples: `/shell ls -la` or `/shell npm test`

### /cmd [command]

Run an OpenCode-specific command. Without arguments, shows an interactive picker.

Example: `/cmd compact`

### /commands

List available OpenCode commands.

## Models

### /models

Display an interactive inline keyboard of available models with capability badges: `[reasoning]`, `[vision]`, `[free]`. The active model is shown with a `✓` prefix. Tap a button to select a model directly.

### /model [id]

View or change the current model via text-based selection.

Examples: `/model` to view current, `/model sonnet` to switch by partial match

## MCP

MCP servers extend the AI with additional tools. Relay includes 4 built-in tools (Browser, Fetch, Memory, Filesystem) that can be enabled during setup. You can also add custom servers.

### /mcp

Show MCP server status for all configured servers.

### /mcp add \<name\> local \<cmd\>

Add a local MCP server.

Example: `/mcp add db local npx -y @modelcontextprotocol/server-sqlite`

### /mcp add \<name\> remote \<url\>

Add a remote MCP server.

Example: `/mcp add api remote https://mcp.example.com/sse`

### /mcp remove \<name\>

Remove and disconnect a server.

### /mcp connect \<name\>

Reconnect a disconnected or failed server.
