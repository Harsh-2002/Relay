## Prerequisites

- [Node.js](https://nodejs.org/) >= 18 (or [Bun](https://bun.sh/))
- A Telegram bot token from [@BotFather](https://t.me/BotFather)
- Your Telegram user ID (get it from [@userinfobot](https://t.me/userinfobot))
- An API key for at least one AI provider (Anthropic, OpenAI, Google, etc. — see [Providers](/docs/providers))

## Installation

### From npm

```bash
npm install -g @4via6/relay
```

### From source

```bash
git clone https://github.com/Harsh-2002/Relay.git
cd Relay
npm install
npm run build
```

## Configuration

Run the interactive setup wizard to create your config at `.relay/config.json`:

```bash
relay onboard
```

The wizard will prompt you for:

- **Bot token** — from [@BotFather](https://t.me/BotFather)
- **Allowed user ID** — your Telegram user ID
- **Provider** — `opencode` (the only supported value)

Provider API keys are set in OpenCode's environment. See [Providers](/docs/providers) for details.

## Run

### Foreground (default)

```bash
relay
```

Or from source:

```bash
npm start
```

### Background (daemon mode)

Run as a background service that survives terminal closure:

```bash
relay start                  # Start as background daemon
relay status                 # Check status (PID, uptime, memory)
relay logs                   # Tail daemon logs (Ctrl+C to exit)
relay restart                # Restart the daemon
relay stop                   # Stop the daemon
```

pm2 is auto-installed on first `relay start`. CLI flags are forwarded.

### Updating

```bash
relay update
```

Auto-detects your install method (npm or git source) and updates to the latest version. Restarts the daemon if it's running.

**Upgrading from v1.0.x:** The `update` command was added in v1.1.0. Run the one-time manual update first:

```bash
# npm
npm install -g @4via6/relay@latest

# From source
git pull && npm install && npm run build
```

After that, `relay update` handles all future updates.

Open your bot in Telegram and send `/start` to verify the connection. Use `/help` to see all available commands.
