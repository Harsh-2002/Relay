Relay supports three coding agent backends. Set `PROVIDER` in `.env` to choose one.

## OpenCode

[OpenCode](https://github.com/opencode-ai/opencode) is the recommended provider with the most complete feature set. The SDK is included as a core dependency — no extra installation needed.

### Start mode (recommended)

Relay spawns and manages the OpenCode server automatically.

```env
PROVIDER=opencode
OPENCODE_MODE=start
OPENCODE_HOSTNAME=127.0.0.1
OPENCODE_PORT=4096
```

### Connect mode

Connect to an already-running OpenCode server.

```env
PROVIDER=opencode
OPENCODE_MODE=connect
OPENCODE_URL=http://localhost:4096
```

### Model selection

Set a default model:

```env
OPENCODE_MODEL=anthropic/claude-sonnet-4-20250514
```

Or change at runtime with `/models` and `/model sonnet`.

### Supported features

All Relay features: sessions, streaming, file operations, todos, diffs, forking, shell access, MCP management, dynamic model listing, and file attachments.

## Claude Code

[Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview) connects to the Anthropic Claude AI.

### Installation

```bash
npm install @anthropic-ai/claude-code
```

### Configuration

```env
PROVIDER=claude
ANTHROPIC_API_KEY=sk-ant-api03-...
CLAUDE_MODEL=sonnet
CLAUDE_PERMISSION_MODE=acceptEdits
CLAUDE_CWD=/path/to/your/project
```

`CLAUDE_PERMISSION_MODE=acceptEdits` is required — other modes require interactive approval that doesn't work in a bot.

### Supported features

- Chat and streaming — Yes
- Sessions — Create, list, delete, fork
- Shell access — Via prompt
- MCP management — Persisted to disk
- Model selection — Dynamic via Anthropic API
- File operations and diffs — Via prompt
- History — Yes
- Todos and sharing — Not supported

## OpenAI Codex

[OpenAI Codex](https://github.com/openai/codex) provides coding agent capabilities using OpenAI's reasoning models.

### Installation

```bash
npm install @openai/codex
```

### Configuration

```env
PROVIDER=codex
CODEX_API_KEY=sk-...
CODEX_MODEL=o3
CODEX_CWD=/path/to/your/project
```

Either `CODEX_API_KEY` or `OPENAI_API_KEY` works. If both are set, `CODEX_API_KEY` takes priority.

### Supported features

- Chat and streaming — Yes
- Sessions — Create, list, delete
- Shell access — Via prompt
- Model selection — Dynamic via OpenAI API
- File operations and diffs — Via prompt
- MCP, todos, and sharing — Not supported

---

## Comparison

All three providers support chat, streaming, sessions, and dynamic model listing. Here's where they differ:

- **File output** (screenshots, generated files) — OpenCode only
- **MCP servers** — OpenCode (full API), Claude (persisted to disk), Codex (no)
- **Todo tracking** — OpenCode only
- **Code diffs** — OpenCode (native), Claude and Codex (via prompt)
- **Session forking** — OpenCode and Claude only
- **Revert changes** — OpenCode only
- **Shell commands** — OpenCode (native), Claude and Codex (via prompt)
- **Session sharing** — OpenCode only

## Switching Providers

Update `PROVIDER` in `.env` and restart the bot. Sessions are provider-specific and not shared between providers.
