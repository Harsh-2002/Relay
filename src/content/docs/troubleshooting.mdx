## Bot won't start

### "BOT_TOKEN is required"

Run `relay onboard` to set up your config, or add your Telegram bot token to `.relay/config.json`:

```json
"botToken": "123456:ABC-DEF..."
```

Get a token from [@BotFather](https://t.me/BotFather).

### "Unknown provider: xyz"

Check `provider` in `.relay/config.json` for typos. Must be `opencode`, `claude`, or `codex`.

### "Cannot find package '@anthropic-ai/claude-code'"

```bash
npm install @anthropic-ai/claude-code
```

### "Cannot find package '@openai/codex'"

```bash
npm install @openai/codex
```

## Authentication

### Bot doesn't respond to messages

Relay only responds to authorized users. Verify `allowedUserId` in `.relay/config.json`. Get your ID from [@userinfobot](https://t.me/userinfobot).

For multiple users, separate IDs with commas:

```json
"allowedUserId": "123456789,987654321"
```

## OpenCode Issues

### "Connection refused" in connect mode

The OpenCode server isn't running or isn't reachable. Check:
1. The server is running
2. `opencodeUrl` is correct in `.relay/config.json`
3. If remote, the port is open

### "Failed to start OpenCode server"

Check that OpenCode is installed and the port isn't already in use.

## Claude Code Issues

### "Invalid API key"

Verify your `ANTHROPIC_API_KEY` environment variable at [console.anthropic.com](https://console.anthropic.com/) and ensure it has Claude Code API access. This key must be set in the coding agent's environment, not in `.relay/config.json`.

### No models listed for Claude

Claude fetches models dynamically from the Anthropic API. If the API key is unavailable or invalid, no models will be listed. Ensure `ANTHROPIC_API_KEY` is set correctly in the environment.

### Claude doesn't modify files

Set `claudePermissionMode` to `acceptEdits` in `.relay/config.json`. Without this, Claude prompts for interactive approval which doesn't work in a bot.

## Codex Issues

### "Invalid API key"

Check your OpenAI API key environment variable. Either `CODEX_API_KEY` or `OPENAI_API_KEY` works. These must be set in the coding agent's environment, not in `.relay/config.json`.

### No models listed for Codex

Codex fetches models dynamically from the OpenAI API. If the API key is unavailable or invalid, no models will be listed. Ensure `CODEX_API_KEY` or `OPENAI_API_KEY` is set correctly in the environment.

## Voice Messages

### "No STT provider available"

Add at least one speech-to-text API key to `.relay/config.json`:

```json
"groqApiKey": "gsk_..."
```

## MCP Servers

### "MCP not supported"

MCP is only available with OpenCode and Claude.

### MCP server shows "failed"

Run `/mcp` to see the error. Common causes: command not found, connection refused (remote), or permission denied.

## Streaming

### Messages appear jumpy

Telegram rate-limits message edits. Relay batches updates to stay within limits, but slight delays on slow connections are normal.

### Long responses get cut off

Telegram has a 4096-character limit per message. Relay splits long responses automatically. If a response seems incomplete, wait for the stream to finish.

## Daemon Mode

### pm2 fails to install

If `relay start` can't install pm2 automatically, install it manually:

```bash
sudo npm install -g pm2
```

### Daemon won't start

1. Make sure the project is built: `npm run build`
2. Check if another instance is already running: `relay status`
3. Check logs for errors: `relay logs`

### Where are daemon logs?

pm2 stores logs in `~/.pm2/logs/`. View them with `relay logs` or access the raw files:

- `~/.pm2/logs/relay-out.log` — stdout
- `~/.pm2/logs/relay-error.log` — stderr

### "relay update" / "relay start" — command not found

These commands were added in v1.1.0. Update manually first:

```bash
# npm
npm install -g @4via6/relay@latest

# From source
git pull && npm install && npm run build
```

## General

### Bot is slow

Check your internet connection, the AI provider's status, and consider using a faster model (`/model haiku` or `/model o4-mini`).

### "Operation timed out"

The AI took too long. Try simplifying your request, using a faster model, or breaking the task into smaller steps.
